# MiniBank — OOP Java Mini Project

## 1. Project Overview
MiniBank is a console-based banking application developed using Java. It demonstrates Object-Oriented Programming concepts and practical banking operations.

## 2. Objectives
- To implement core Object-Oriented Programming concepts.
- To manage bank accounts and customer information.
- To perform deposits, withdrawals, and fund transfers.
- To validate input and handle banking exceptions.
- To demonstrate multithreading and concurrency.
- To store and retrieve account data.

## 3. Technologies Used
- Java JDK 17
- IntelliJ IDEA
- Git and GitHub

## 4. Main Features
- Open and manage bank accounts.
- Deposit and withdraw money.
- Transfer funds between accounts.
- Validate account details and transactions.
- Handle banking exceptions.
- Calculate account interest.
- Use threads and synchronization for concurrent operations.
- Store account and transaction information.
- Generate account and transaction reports.

## 5. OOP Concepts
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Interfaces
- Exception Handling
- Generics
- Collections
- Multithreading
- Serialization
- Annotations

## 6. Project Structure
The project is organized into Java packages such as `model`, `util`, and `service`.

- `exception` -  Custom banking exceptions and exception-handling classes.
- `model` — customer and account-related classes.
- `util` — validation and utility classes.
- `service` — banking services and application entry point.

## 7. How to Run
1. Install JDK 17 or later.
2. Open the project in IntelliJ IDEA.
3. Configure the project SDK.
4. Open `service.MiniBank`.
5. Run the `main()` method.
6. Follow the console menu to perform banking operations.

## 8. Conclusion
MiniBank demonstrates the practical application of Java and Object-Oriented Programming concepts through a simple banking system.
